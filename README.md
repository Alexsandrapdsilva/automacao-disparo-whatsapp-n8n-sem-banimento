# automacao-disparo-whatsapp-n8n-sem-banimento
🚀 Automação de disparo em massa para WhatsApp via n8n e Evolution API. Inclui sistema anti-ban com intervalos aleatórios, banco de dados via Google Sheets e atualização automática de status de envio. Ideal para prospecção segura e escalável de clientes. 📲✨
